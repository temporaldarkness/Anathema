# @aspects/cards

Все определения карт живут в `src/data/*.json`. Схема — в `src/schema.ts`.

## Пакеты

| Файл | Назначение | Карт |
|---|---|---|
| `stormwind.json` | Штормград — дисциплина и оборона | 28 |
| `voidflame.json`  | Пламя Пустоты — жертва и агрессия | 30 |
| `legends.json`    | Легендарные карты | 14 |
| `tokens.json`     | Токены (призываются эффектами) | 7 |

## Валидация

После правки любого JSON:

    pnpm --filter @aspects/cards validate

Проверит:
- соответствие Zod-схеме
- уникальность id во всех пакетах

## Правила

- Поле `rarity: "legendary"` — не более 1 копии в колоде (проверяет движок).
- Поле `isToken: true` — карта не может быть в колоде, не попадает в сброс.
- Токены должны присутствовать в `tokens.json`, иначе `SUMMON` не сработает.
- Если у двух карт совпадает `personalityTag` — их можно менять (см. правила игры).
